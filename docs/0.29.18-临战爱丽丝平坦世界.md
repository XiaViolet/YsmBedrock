# 临战爱丽丝的平坦世界帧耗与烟尘

同一台电脑分别运行 Java Edition 1.21.1、YSM 2.6.5 Fabric 正式包和 Windows 基岩版 1.26.60.05、LeviLamina 26.60.8。模型文件夹的 43 个文件逐个比对 Java 使用的 ZIP，路径和字节全部相同。完整 SHA-256 见 `integrity.json`。

## 同场实测

两端新建石面平坦世界，石面下有两层泥土和一层基岩，平原、晴天正午。玩家在 (100.5, -60, 100.5) 空手，第三人称正面，固定朝向和俯仰。两端窗口可见、帧缓冲 2560 × 1351、FOV 60°、视距 16 区块、精美画质、关闭垂直同步，均保留快捷栏并关闭角落的额外纸娃娃。Windows 显示器为 144 Hz，表中 FPS 表示游戏渲染或提交的速率。两端着色、相机和 GUI 仍各自使用本端的实现。

| 版本与条件 | 原版角色 | 临战爱丽丝机甲 | 机甲平均每帧 |
| --- | ---: | ---: | ---: |
| Java 2.6.5，两轮 | 1704.7 / 1733.5 FPS | 534.4 / 548.0 FPS | 1.85 ms |
| 基岩 0.29.17 | 288.0 FPS | 88.3 FPS | 11.32 ms |
| 基岩 0.29.18，两轮机甲 | 288.0 FPS | 88.7 / 89.5 FPS | 11.22 ms |

Java 每轮按世界绘制回调的帧数除以累计秒数计算。第二轮还在每秒读取游戏内置 FPS，机甲期间内置平均为 **546.1 FPS**。基岩版用同一进程主交换链的 DXGI Present 起始事件计数，并用模组帧回调交叉核对。Java 每条件每轮约 35 秒，基岩每次约 24 秒。基岩 .18 两次机甲帧间隔的第 95 百分位分别为 12.93 和 12.70 ms。隐藏窗口、重进旧存档、显示额外纸娃娃或使用灵动视效的探索数据单独保留，均未计入上表。[Java 内置帧率接口](https://maven.fabricmc.net/docs/yarn-1.21.1+build.3/net/minecraft/client/MinecraftClient.html#getCurrentFps())

## 剩余耗时

按同端的原版角色扣除，开启机甲后 Java 多用 **1.27 ms/帧**，基岩版多用 **7.75 ms/帧**。基岩版可见机甲共 6,896 根骨骼登记到骨架；两段测量的动画求值分别为 5.87 和 5.82 ms，姿势应用均约 0.83 ms，准备阶段约 0.10 ms。每帧平均仍有约 353 次材质通道和 174 次发光通道。这是 CPU 分段计时和渲染提交计数，未取得逐通道 GPU 耗时或 Java 对应阶段的 CPU 计时。

在同一个基岩版 .18 客户端里，仅将模组自己的普通营火粒子设置为首次更新时过期，再重启进相同世界。原包、机甲、粒子脚本和提交请求都保留。此时看不到烟环，实际活粒子为零，录得 91.36 FPS，与正常烟尘的观测差为 **0.28 ms/帧**。这项对照保留了脚本、分组、发射和初始化成本，不能把差值当成所有粒子工作的耗时。

基岩播放器在角色绘制时同步求值。当角色连续可见、实际帧率低于当前 120 Hz 采样上限时，几乎每个新帧都会运行一次控制器和骨骼求值。本轮回放的主要热点为 `player.pre_parallel_0`（1.58 ms）和 `player.parallel_3`（1.19 ms，其中 `parallel3` 骨骼通道 1.07 ms）。这是固定一个逻辑核心的 96 帧插桩回放，父子耗时有包含关系。工程固定的 Java 源码在 `AnimatableEntity.tickAnimationNow` 区分绘制和控制器推进，`AnimationProcessor` 使用整数骨骼索引和活动骨骼队列；基岩版的 `Pose` 和分层输出仍按骨骼名字在有序表中查找。这为下一步改用加载期绑定的骨骼索引提供方向。正式包各项内部成本尚未单独测量。

## 脚边烟尘

普通营火烟雾使用模组自身的粒子定义和基岩原版 12 格营火图集。12 格与 Java 对应烟雾图片的可见 RGBA 像素逐格相同。共用发射代码保留作者指定的位置、水平速度和寿命，以 Java 普通营火的初始竖直速度、稳定随机尺寸和淡出方式渲染。近距离、相邻、同类型并在同一视角的请求可以共用发射器。世界和第一人称、信号烟和普通烟、跨越其他粒子的调用仍分别处理。

临战爱丽丝脚边的烟点寿命为 15 tick。旧版一次实机快照为 264 点、264 个发射器；新版为 240 点、9 个发射器。新版另一计数窗口的 4,872 次请求全部成功生成。本次跟踪的 24 点一批中，一个粒子在首次模拟后半尺寸为 0.533，随后形状维持，透明度从 0.90 降至 0.69。发射瞬间原生对象的初始化字段仍是尺寸 1、透明度 1；首个模拟步才应用粒子资源。旧版蓬起的烟遮到腿部；新版和 Java 都能看到机甲脚下环绕的地面，基岩画面里的烟和石面仍偏亮，随机分布也有差异。

## 验证和复现文件

工作区 `build/verification/perf-0.29.18/` 内有以下记录。

- `烟尘对照.jpg`、`java/alice-after.png`、`game/flat-017-fancy.jpg`、`game/flat-018-mech-B.jpg` 为游戏实拍，`game/flat-018-smoke-expired.jpg` 是烟尘提前消失的对照。
- `worlds.json` 记录两端生成器和层，`java/frames.tsv` 的第四列是第二轮的内置 FPS，`java/foreground-A/frames.tsv` 是第一轮，`game/*-dxgi.json` 保留逐帧间隔计算所需的提交时刻，`summary.json` 为汇总。
- `game/0.29.18-mech-*-fps.json`、`controller-profile-final.log` 和 `alice-animation-foreground-profile.json` 可核对各阶段耗时。游戏中 62 个物理状态持续更新，机甲待机测量的运行表达式错误为零。待机、走动、停步的离线状态回放结果为 14 个时点的完整状态摘要与 0.29.17 逐帧相同。原有 `parallel1` 时间轴的编译诊断见状态文件。
- `tests.log` 记录 957 项自动回归。`campfire-batch.log` 记录实际编译执行的 C++ 测试，核对了顺序、坐标、速度、寿命、128 点分组上限和视角边界。`game/particles-full.json`、`game/particles-before.json` 对应烟尘实测。`sprite-pixels.json` 记录图集像素核对。
