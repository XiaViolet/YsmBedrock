## 0.28.0 已接入

- 动画可读玩家经验等级、镜头空间、准星目标、群系标签及物品使用时长。身体、第一人称和替换实体的指令关键帧按 `merge_multiline_expr` 合并或分别执行，兼容旧源包的多段变量名。群系标签取自已固定的 Java 原版和 Forge 数据。
- 尘埃、方块和物品粒子支持 Java 的空格参数格式。载具、投射物和远端玩家可派发自己的音效与粒子。新增鱼钩状态、投掷物物品类型、箭插地时间及发射者常用属性。
- 模型库可显示作者指定的前景、背景、无阴影与固定预览方向。玩家模型普通不透明表面可请求 `all_cutout` 面剔除，胸槽鞘翅可跟随 `ElytraLocator`。本地设置加入可移动的实时角色小窗，Alt+B 查看动作、等级和脚本错误。
- 中继可全局或逐人屏蔽模型，也可根据当前可见玩家和客户端收到的实体归属事件更新替换模型。双人外观、原生粒子与鞘翅绑定效果仍待实机验收。

待接入的原版行为包括完整渲染层顺序、肩上鹦鹉定位、实体归属的服务器持久化与跨客户端权威同步，以及服主游戏内指令。保留 v3 `.ysm` 直读花屏问题。

863 项自动检查通过。8 个本地源包的内容标识与 0.27.1 一致。授权版爱丽丝原始脚本离线验证 30／31 级的剑盾与剑刃特效分支，仍有原有的 `math.exp` 溢出诊断。昔涟 v1.4 和香奈美的作者图层通过离线预览检查，香奈美仍有 3 次脚本执行上限诊断。

0.28.1 复核正式包后修复了爱丽丝特效曲线的单精度溢出。原包各组合的离线结果见《进展.md》。

0.28.2 加入 Java 的结构化粒子选项，以及在基岩版按木材、船型和投射物 ID 匹配作者实体模型。补足实体着火、乘客、箭插地时长、鱼钩与投掷物等输入的独立采样。对应测试和未覆盖的跨存档同步范围见《进展.md》。

LeviLamina 26.60.8 测试实例已核对所需的 57 个加载器导出及 4 处原生模型入口签名。新版待游戏内验收。[加载器发布说明](https://github.com/LiteLDev/LeviLamina/releases/tag/v26.60.8)

## 0.27.1 核对记录
