# 0.29.2 动画时长与分组验收

Java 基准为 Minecraft 1.21.1、Fabric 0.18.4、YSM 2.6.5 正式包 `ysm-2.6.5-fabric+mc1.21.1-release.jar`。SHA-256 为 `A66B7265A2761D639C48F61A64179206ADF5D81C38F360763FC8275A0FEC9FA5`。基岩版使用 Minecraft 1.26.60.05、LeviLamina 26.60.8 与 YsmBedrock 0.29.2。固定源码 `15c2c25` 的默认时长是 `Float.MAX_VALUE`，实测正式包运行时为无穷大。[正式发布](https://modrinth.com/mod/yes-steve-model/version/eGOUtHWJ) · [固定源码](https://github.com/YesSteveModel/YesSteveModel/commit/15c2c25f5b50f54ee099bc474483dc4b588d956d)

## 动画时长与事件

审查中的故障在 0.29.1 复现。省略时长的零时刻片段被判为零秒，导致位移停止或开始事件随更新重复。修复位于共用采样器和时间线。导入保留显式零和有限时长，缺省时先看骨骼关键帧。无限时长的首轮时间线用原事件时间求值，确保正常触发。

Java 游戏内探针从已加载的正式版动作库取片段，调用发行版播放器。基岩版用同一逻辑时间输入共用播放器。每种输入测试单次、循环和末帧保持，共 15 组。加上两个原包片段，119 个采样点的播放阶段和事件次数一致。采样为 0、0.05、0.25、0.5、0.75、0.875、1.05 秒。

| 输入 | 双端回放结果 |
| --- | --- |
| 省略时长，仅有零时刻骨骼通道 | 运行至 1.05 秒时 X 位移为 10.5。第零帧事件仍为一次，0.875 秒事件各触发一次。 |
| 省略时长，只有时间线 | 时钟继续推进。第零帧与 0.875 秒事件各一次。 |
| 省略时长，最后骨骼关键帧为 0.5 秒 | 单次在 0.5 秒进入结束过渡，循环后再次派发第零帧事件，保持模式的 X 位移持续为 5。 |
| 显式零时长 | 保持模式锁在零时刻。循环模式在起播与六次向前更新后，第零帧事件累计为 7。 |
| 显式时长为 0.75 秒 | 按 0.75 秒边界播放。1.05 秒采样的末帧保持 X 位移为 7.5。 |

爱丽丝的所测位移最大差为 0.000065 模型单位。香奈美片段中所测旋转通道最大差约 0.000240°，旋转已统一坐标符号和角度单位。双端原包内容分别核对 43 和 53 个文件。基岩版测试世界已载入并绘制爱丽丝。实机测试使用同版本的路径校验加固前构建，正式预览包已重跑全量回归。表中位移和旋转来自片段求值。游戏内叠加其他控制器后的最终姿态幅度仍待同场景双端核对。

## 导入与动作分组

0.29.1 可因未知组的重名或无法解析的内容拒绝启用整包。0.29.2 按 Java 正式版处理已存在的未知组资源。导入器验证其引用存在，动画库忽略其内容。测试包 `ClockGroupsUnknown.zip` 在基岩版测试世界切换后显示模型。格式错误的未知组资源亦可加载。未知组指向缺失路径时，基岩版报告 `Missing resource`，Java 的已加载注册表中未出现该包。

九个可加载样包的 466 个动作与作用域对照项全部一致。其中，116 个有效身体组重名用例采用相同来源，30 个跨视角重名用例保留独立的第一人称定义。反转清单顺序后结果相同。身体组优先级按低到高为 `slashblade`、`carryon`、`tlm`、`irons_spell_books`、`immersive_melodies`、`extra`、`tac`、`main`、`swem`、`arm`、`parcool`。作者身体动作仍可覆盖默认动作，第一人称 `fp_arm` 和额外动作均有针对性回归用例。
