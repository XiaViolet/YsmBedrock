## 0.29.5 双端实机复验

| Java 脚本输入 | 正式版行为与基岩画面 |
| --- | --- |
| `vibration` 方块位置 | 两端均出现振动信号。基岩使用可辨认的青色弧线，路径和外观仍属近似。 |
| `vibration` 实体位置 | Java 2.6.5 正式版的粒子编解码器拒绝实体来源。存在、移动和移除目标的对照得到相同拒绝。两端都保留此前的合法粒子，并立即中止这条表达式，后续标记没有出现。 |
| `ash`、`white_ash` | 两端可分辨灰、白两类。基岩使用原生飘尘图块，粒径、纹理和下落轨迹有差异。同批灰烬共享一档随机灰度，Java 按粒子取样。 |
| `crimson_spore`、`warped_spore` | 两端分别显示粉红和深蓝色。基岩使用着色方点，原生精灵、粒径和随机轨迹与 Java 有差异。 |
| `item_cobweb` | 两端均可见独立的白色镂空碎片。基岩传统分发接口没有返回粒子指针，无法按请求覆写和逐帧核实其寿命，仍列为近似。 |

两端实机裁图和连续基岩画面见验收包 `particles/particle-comparison.png`、`particles/bedrock-motes-and-web.gif`。其他已知近似仍包含破蛋时出现白色闪点、大小阵风使用基岩风爆形状。此次核对的八份原包未发现上述振动和五类外观粒子的直接调用，本轮采用独立测试包，保留作者包原样。
