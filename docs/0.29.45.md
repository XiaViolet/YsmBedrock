# YsmBedrock 0.29.45

此预览版基于合并 PR #1 后的主线 `8b7dadc`，保留了中英文界面和图标更新。

| 项目 | 修改与实测结果 |
| --- | --- |
| 伊蕾娜上下飞行 | 玩家位置与采样间隔共用游戏刻和同一插值分数。在测试世界用原包连续上升、悬停、下降，持续上升阶段抽样的垂直速度从旧版约 7.59–8.17 收敛到 7.50 格/秒，悬停归零，稳定下降约为 −11 格/秒。 |
| 香奈美放置作者人偶 | 在转盘点动作旁的「设置」或右键扇区，开启「人偶开关」，再点「执行此动作」。设置页执行的是打开该页的动作，即使多个动作复用同一个表单也能区分。直接点动作扇区仍可播放。原包会将人偶放在角色当时的位置，第三人称退开后可观察。 |
| 临战爱丽丝解除机甲 | 原包启用第 3 个右手挂点时，附件准备、绘制和绘制结束后的绑定均沿用有效挂点。在测试世界分别切换到木矛和重锤，两件物品已恢复显示。 |
| Arke | 使用[上游 0.1.7 发布附件](https://github.com/LiteLDev/Arke/releases/tag/v0.1.7)和 Photon 1.4 实测。固定世界时间、低头、显示快捷栏，连续观察 90 帧第一人称地面投影。升级 Arke 即可使用现有渲染路径。 |

测试环境为 Windows x64、Minecraft 1.26.60.05、LeviLamina 客户端 26.60.9 和 RTX 4060 Laptop GPU。以上画面均取自单人本地世界，多人视角及其他光影包未在本轮复验。Arke 上游 0.1.7 压缩包内的 manifest 仍写作 0.1.0，本次以官方发布资产的 SHA-256 确认版本。
