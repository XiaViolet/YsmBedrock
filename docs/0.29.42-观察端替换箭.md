# BedrockBoot 观察房主的替换箭

适用版本为 Minecraft Windows 1.26.60.05、YsmBedrock 0.29.42。复现环境为 LeviLauncher 房主使用临战爱丽丝、BedrockBoot 客人从侧面观察。

## 定位

0.29.41 的同房记录中，房主射出的四支弓箭在客端收到的实体 ID、射手和发射物品一致。两端日志时间分别相差 84、87、61 和 74 毫秒。此前的版本检查要求游戏映像总大小等于 0x13847000。BedrockBoot 的附加节把总大小增至 0x16c7d000，实际执行代码、只读数据和异常表三个节逐字节一致。客端因此会在创建箭的原生替换模型时退出。

0.29.42 按固定游戏版本的时间戳、机器类型和引擎代码及只读数据的布局进行校验，继续核对对象的虚表及构造函数签名。原包声明、动画选择和房间协议沿用原有实现。

## 复验

新回归在 Windows 上将两个启动器的真实游戏文件分别映射为不可执行映像，调用模组使用的同一套检查。旧检查仅通过 LeviLauncher，新检查两者均通过。错误的对象类型和移动过的只读数据节均被拒绝。

工作区的 `build/verification/observer-arrow-0.29.42/` 保存四发逐支比对（`paired-shot-and-layout.json`）、新旧兼容检查输出（`layout-check.txt`）以及构建和测试日志（`build.log`）。构建内的 970 项检查通过。

## 同房实机结果

两端均安装并实际加载 0.29.42。房主穿戴临战爱丽丝，用弓、弩发射，玩家在 BedrockBoot 客端完成目视复验并确认故障已修复。同一支箭在两端的 ID、射手与发射物品相符。客端的目标模型使用原包骨骼，飞行阶段选择 `air`，入地选择 `ground`。

| 房主武器 | 两端相同的箭实体 ID | 客端入地骨骼数 | 客端已采到的入地网格绘制次数 |
|---|---:|---:|---:|
| 弓 | -2723009265528 | 238 | ≥975 |
| 弩 | -2723009265493 | 238 | ≥4332 |

绘制计数是采样时的累计值。客端两支箭的入地样本均记录零次网格匹配失败。工作区证据目录下的 `live-room-0.29.42.json` 记录逐发收发与原生绘制阶段，`guest-shot-draws.json` 记录客人端的武器查询值、动作、骨骼数和网格绘制次数。独立 BeDD 世界的弓、弩复验另存为 `bedd-shot-draws.json`。房间协议回放和安装包回归均通过。

客人进入世界约 1.8 秒后，房主还射过一支弓箭（-2723009265616）。该发在房主端有记录，在客端没有找到对应的归属记录。代码在穿戴模型尚未获准发布时跳过箭记录，这次采样不足以确认它就是该发的原因。刚进房便发射的情况仍待单独复验。
