# 临战爱丽丝性能复验

本轮的模型是「临战爱丽丝」源包。Windows 基岩版读取原目录，Java YSM 2.6.5 正式版读取已有的 ZIP。两份的 43 个相对路径与文件内容逐个相同。证据目录为 `build/verification/perf-0.29.17`。

## 同一个模型在两端的工作量

Java Edition 1.21.1 测试只加载 Fabric API、YSM 2.6.5 和记录世界渲染帧的测试模组。角色使用临战爱丽丝原皮肤、机甲形态，第三人称正面、空手、晴天。2560 × 1351 的实际帧缓冲与基岩版客户区尺寸相同，两端视距均为 16 区块，关闭垂直同步。Java 的独立石台测试世界（复核存档生成器为普通地形）与基岩版的森林石台在地形、光照、实体和粒子外观上有差异。Java 分辨率实图、选模记录和逐秒世界渲染帧在 `java/`。

固定 Java 源码 `15c2c25` 的 `NativeModelState.java` 从当前姿态提取可渲染骨骼与顶点，`NativeRenderer.java` 依实际顶点数向宿主申请输出。基岩版将模型骨骼绑定到原生蒙皮网格，再为不同颜色、透明度和发光状态准备绘制。两端使用不同的渲染器。正式版帧率来自实际运行，固定源码用于追踪设计。

## 实机帧率

同一台电脑的 Java 正式版在普通地形的石台上记录了 35.15 秒、3,884 个世界渲染帧，平均 **110.49 FPS**。基岩版在同一存档、同一站位和视角、机甲保持开启的条件下，每个版本各测两次 36 秒。下表基岩 FPS 采用游戏读数，每帧材质通道数为模组计数器在采样窗口内的差分。

| 基岩版指标 | 0.29.16 | 0.29.17 |
| --- | ---: | ---: |
| 两次平均 FPS | 67.16 / 68.59 | 72.32 / 73.78 |
| 合并平均 FPS | 67.88 | 73.05 |
| 逻辑动画每次耗时 | 6.55 ms | 5.88 ms |
| 每帧材质通道处理次数 | 507.19 | 353.17 |
| 其中发光通道 | 327.69 | 174.17 |

同场实机帧率提升 **7.6%**。新版每帧平均省掉 154.02 次完全隐藏的材质通道，另有 76.06 次混合网格省去了遮罩矩阵复制。GPU 剩余耗时未分项测量。Windows DXGI 对新版的独立观测在单一交换链 20.06 秒记录到 1,492 次呈现，约 74.33 次/秒。另一次恢复原版外观的附测约 281.75 次/秒，天气有变化，仅作同机参考。原始文件为 `game/0.29.17-*-dxgi.json`、`bedrock-ab.json`、`game/*-fps.json` 与 `java/render-fps.json`。

## 本次改动

- **动画采样**。爱丽丝主体动画有 9,585 处字符串表达式，仅 1,306 种不同文本。`parallel3` 有 434 条旋转轨道、845 处表达式，仅 32 种文本。共用播放器复用不可变编译程序，并在一次采样中复用当前轴输入槽。每个关键帧和每根骨骼各自执行，保留脚本副作用、物理和事件。固定同一 CPU 核心正反序回放 108 帧，去除前 12 帧，旧版动画 CPU 中位时间为 6.70 / 6.55 ms，候选版为 6.08 / 5.81 ms。
- **混合材质网格**。源模型 50,713 个方块中，待机连续两帧有 45,976 个随自身或祖先缩放到一点。旧版仍会为混合网格里完全隐藏的一组材质准备遍历和绘制。新实现仅在上帧与当前帧该组所有骨骼均完全塌缩时略过该组。某一帧仍可见、矩阵不齐或透明部件可能暴露时，保留原有绘制。若只剩一种安全可见的材质，直接提交该材质，省去复制及遮罩整组矩阵。

## 正确性

在已安装的新 DLL 中操作作者转盘。选「阿比舒解除」后机甲与大片烟尘消失，校服和扫地机器人出现；再选「阿比舒启动」看到了组装平台、机械臂、发光面板及重新出现的机甲。两次均记录 62 个物理状态，运行表达式错误为 0。截图和状态见 `game/0.29.17-release-*`、`game/0.29.17-reactivated-*`。

957 项自动测试通过，详见 `tests-final.log`。临战爱丽丝待机、走动、停步的 14 帧完整播放器结果逐帧相同。另回放解除、重新上甲，核对两端点与插值中点的可见骨骼和材质，33,195 项检查通过。另有 2,304 组双帧合成用例和两项针对性优化断言。原包 `parallel1` 时间线 0 的第 41 条指令缺少右括号，Java 2.6.5 正式包及两版基岩播放器均在第 79 列报错；本轮未修改作者脚本。另用香奈美（打开尾巴）、蓝色大肥鱼和临战爱丽丝各回放 10 帧；三份原包均通过历史指纹校验，新旧两版的完整帧输出与诊断逐项相同。见 `other-pack-regression.json`。

## 保留的表现差异

基岩版的脚边烟尘比这次 Java 画面更大、更亮。原包烟环每秒 13 组关键时刻，每组 24 次营火烟调用。按逻辑周期核对后，基岩版累计 42,984 次请求与已到达的关键帧组吻合，成功映射到原生 `minecraft:campfire_smoke_particle`。Java 原生营火烟初始透明度为 0.9，原包给的 15 tick 寿命会使它从首次更新起淡出；基岩版实录初始透明度为 1。两端原生粒子的尺寸参数也不同，Java 约为 0.3–0.6，基岩资源从 0.75 起步。两端的实际屏幕占用和 GPU 时间仍待单独测量。见 `alice-smoke-baseline.json`。
