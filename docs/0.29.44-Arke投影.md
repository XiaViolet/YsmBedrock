# 0.29.44 · Arke 第一人称投影

## 修复

0.29.43 在固定时间、第一人称低头且快捷栏可见时，头顶和肩部的地面投影会在两种轮廓间跳变。按 F1 隐藏界面后投影稳定。0.29.44 将玩家朝向的采集提前到游戏绘制手臂之前，供身体动画和投影共用。

## 复验

Minecraft for Windows 1.26.60.05 使用 Arke 与 Photon 1.4，模型为「新伊蕾娜 V2」。在固定机位显示快捷栏，比较同一投影区域相邻帧的平均绝对亮度差峰值（亮度范围 0–255，每轮 90 帧）。

| 版本 | 峰值 |
| --- | ---: |
| 0.29.43 | 25.91 |
| 0.29.44 | 1.02 |
| 0.29.44（重复一轮） | 1.48 |

维护者随后在日常实例复验，确认该处闪烁已修复。开发工程的 `build/verification/arke-shadow-44/` 留有本轮录像和测量记录。
