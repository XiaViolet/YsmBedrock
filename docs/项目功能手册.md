# YsmBedrock 项目功能手册

当前功能与验收状态见[Java 功能对照](Java功能对照.md)。下文的功能验收保留当时的版本和证据。安装与快捷键已更新到 0.29.20。

**适用版本**　基岩版 Windows 客户端内测包 **0.29.20**，Minecraft **1.26.60.05**。项目列出 LeviLamina 26.60.7／26.60.8，本文引用的游戏内验收使用 26.60.8。Java 对照选用 **Minecraft Java 1.21.1、Fabric、Yes Steve Model 2.6.5 正式版**。核对日期为 2026-11-19。[Java 正式版](https://modrinth.com/mod/yes-steve-model/version/eGOUtHWJ) · [基岩版工程说明](../README.md)

YsmBedrock 让 Windows 基岩版玩家装入 Java YSM 作者提供的模型包，在游戏里使用其外观、动作、脚本、声音，以及为载具和投射物声明的替换模型。实现已经覆盖从读取原包到游戏绘制的整条路径。兼容程度取决于原包实际用到的行为。例如，同一支箭可以正确选中作者的模型、播放入地动画，却因为取发射物品的时刻不同，亮起和 Java 不同的骨骼。

## 安装与操作

退出游戏，将预览包的 `mods` 合并到对应的 Windows 客户端实例。把模型放入实例的 `mods/YsmBedrock/models`，保留作者原包。0.29.20 公开包内置官方基础款酒狐，另附 v3 读取库和启用替换实体绘制的 `target-render-probe.enable`。进世界后按 **Alt+Y** 打开模型库，选中模型，再测试它实际声明的动作或实体。

| 想做什么 | 操作 |
| --- | --- |
| 选模型、换贴图、看作者信息或预览 | Alt+Y 打开模型库。支持搜索、收藏和翻页。在模型库选择要穿戴的模型，在「贴图」页切换贴图。 |
| 显示原皮肤或重新启用模型 | 在模型菜单点击「恢复原版」或穿戴模型。每个模型可以记住自己的贴图。 |
| 使用作者的额外动作或设置 | Z 打开转盘，1–8 选当前页，滚轮或 PgUp／PgDn 翻页，Esc 返回。装饰在右侧调整，左侧纸娃娃显示当前角色。普通动作选中后关窗；有「设置」的扇区可单独打开作者选项。纸娃娃在本地设置中可调 5–30 FPS。 |
| 单独观察一个动作 | 在「动作预览」中选择片段，在转盘中播放或停止作者动作。 |
| 查看运行状态 | 转盘中央的「动作锁」可切换移动时是否保留额外动作。关锁后，关闭转盘并走动、跳跃或潜行会停止播放。 |
| 只隐藏某类外观 | 本地设置可分别控制自身模型、自己的手部、投射物、载具和其他玩家。角色小窗可调整位置、大小和角度。 |

## Molang、物理和游戏输入

Molang 是作者用来决定“什么时候动、动哪根骨骼、发什么效果”的表达式语言。相同脚本在检查器里能算出正确结果，进世界后也可能因为采集的是另一个实体、另一刻的状态而选错分支。

| 功能 | 0.29.2 已实现 | Java 对照与使用边界 |
| --- | --- | --- |
| 表达式、数学与作者函数 | 支持数值、字符串、数组、对象和向量、变量、数学函数、嵌套作者函数、参数与局部作用域；有计算预算和编译／求值诊断。 | 许多数学用例对照过 Java 方法。个别原包仍有不支持的通道，完整案例见文末绘梨衣记录。 |
| 生命周期函数与动作控制 | 支持初始化、更新、动作处理、延迟回调与同步事件。作者可影响控制器继续、停止、暂停等行为；失败批次有避免部分特效生效的处理。 | 有执行顺序、回调作用域、失败恢复与只读观察回归。同步事件的本地执行和远端玩家收到属于不同验收项。 |
| 骨骼查询与动态外观 | 可读旋转、缩放、相对位置和枢轴；可按骨骼写颜色、透明度和发光。求值区分上一姿态、当前动作和渲染观察。 | 玩家、箭、船各有动态骨骼材质实机样例。复杂模型里多个脚本和原生附加层同帧参与时，仍需逐项对照。 |
| 一阶／二阶物理 | 为作者的跟随、摆动等表达式保存状态，区分身体与手臂的物理实例，支持长帧间隔后继续求值。 | 香奈美尾巴有 48 帧定向回放。该记录验证给定输入下的轨迹，游戏镜头下的所有物理效果尚未逐模型对照。 |
| 玩家、装备、输入设备 | 提供速度、视角、生命、经验、主副手、装备耐久与附魔、使用时长、挥击、键盘和模组版本等查询。按游戏键事件转换作者使用的按键编号。 | 有参考向量和边界测试。Java 独有的物品、附魔或联动模组数据在正常基岩版玩法里可能无法取得，因而作者写出的条件也可能无法触发。 |
| 世界、相机与命中目标 | 可查询时间、雨雷、露天、群系与标签、相对方块、相机方向与准星目标。 | 0.29.2 玩家的输入和替换实体的输入路径有差异，雨中露天条件可能在玩家身上成立、在同位置的替换实体上落入另一个分支。0.29.3 的源码变化见后。 |
| 漫游变量与同步值 | 按模型身份维护作者声明的漫游变量，区分全量和增量；可在同一会话恢复模型，按声明向手臂投射共享字段。 | 有切模、恢复、断线及旧任务隔离回归。本地贴图设置、会话内变量和服务器跨存档保存是三种不同寿命。 |
| 第三方模组联动 | 导入器识别若干 Java 联动分组，可读到组里的作者动作，也会报告尚未接入的联动。 | Java 的枪械、跑酷、拔刀剑、马术、Carry On 等依赖各自模组提供的实际状态。绘梨衣原包在发行检查器中就报告了五个未接入组。 |

## 粒子和声音

**作者自己的粒子效果要看原包用什么方式做出。** 作者可以在某个时间点运行脚本，把许多原版粒子按指定位置、速度与颜色组合成花瓣或刀光，也可以用发光骨骼模拟特效。前者经过粒子映射，后者经过动画和材质。如果脚本引用第三方注册的粒子 ID，还要有对应的游戏粒子提供者。这三种情况看起来相似，缺失的原因不同。

| 功能 | 0.29.2 已实现 | Java 对照与使用边界 |
| --- | --- | --- |
| 脚本粒子与空间 | `ysm.particle`、`ysm.abs_particle` 支持偏移、朝向、速度、数量、散布和寿命；玩家、远端玩家与被替换实体可产生自己的事件。 | 有单粒、批量、身体朝向、非玩家朝向和作用域回归。香奈美的箭有回放中派发 9 次樱花粒子的记录，整段效果的双端画面仍待核对。 |
| 原版粒子注册表 | 对固定的 **Java 1.20.1** 注册表，95 项里有 **52 项可对应、36 项近似、7 项缺失**。另有少量较新 ID 的映射。 | 数量是映射表覆盖范围。游戏内已有横扫、魔法暴击、伤害心形和火焰的画面记录。横扫用 13 个末地烛粒子排成弧，外形会与 Java 有差别。 |
| 参数和资源 ID | 识别尘埃颜色、颜色过渡、方块、物品、部分结构化参数和旧式空格参数。 | 方块／物品碎片取基岩端状态或图标，尖啸延时尚未按 Java 时序表现。Java 通过游戏粒子注册表解析 ID；本版查固定的 `minecraft:` 映射表，任意作者／第三方命名空间的 ID 没有通用加载路径。 |
| 无画面的粒子 | 已知缺失项会被记录；同段脚本后续可绘制的已收录粒子仍可派发。 | 七项为 `ash`、`crimson_spore`、`egg_crack`、`flash`、`vibration`、`warped_spore`、`white_ash`。一个合法调用被记录，不代表玩家能看到效果。 |
| 模型声音和原版音效 | 读模型中的 Ogg Vorbis／Opus，解析游戏声音 ID；脚本或控制器可按作用域、ID、音量、音高与循环方式播放、替换或停止声音。 | 有编解码、控制器切换和停止行为回归。游戏声音还取决于基岩端是否有对应资源，任一原包的最终听感需实机检查。 |
| 声源位置与音量 | 音效在事件原点启动；记录句柄、开始、停止和资源缺失，可清理失效实例。 | Java 的移动声音会按实体位置和当前设置更新。本版长音启动后缺持续的位置／音量更新，移动中声源可能留在起点；调本地模型音量会停止正在播放的模型声音。 |

粒子 ID 经过[选择器与映射](../src/ModelParticles.cpp)再进入[原生派发](../src/NativeModelParticles.cpp)。声音经过[资源解析](../src/ModelAudio.cpp)和[游戏播放](../src/Mod.cpp)。分类全表及游戏记录见[粒子与实体材质验收](Java粒子与实体材质.md)。

## 载具、投射物与实体替换

这里的“替换实体”指作者给特定载具或投射物声明自己的几何、纹理、动画和控制器。例如玩家射出箭后，飞行中的箭会有自己的模型、时钟、脚本输入和绘制状态。当前导入器的目标种类是载具和投射物，不能据此推断任何生物都能作为独立替换目标。

| 功能 | 0.29.2 已实现 | Java 对照与使用边界 |
| --- | --- | --- |
| 目标选择与归属 | 按目标种类、原版 ID、别名、标签或船的木材变体匹配作者声明；选择首个匹配项。载具按首位乘员建立归属，投射物可保存发射时的模型快照。 | 0.29.2 的游戏路径会把实体实例标签传入类型标签匹配。Java 类型标签和临时加给单个实体的标签含义不同，某些模型会误选。跨存档归属也仍有缺口。 |
| 载具外观与骑乘动作 | 支持独立船体等模型、纹理、控制器和动态材质，区分有无乘客、水面、地面和运动状态。玩家自己的骑姿也有独立入口。 | 有已乘坐船只的世界绘制和材质样例。不同船型、矿车俯仰、上下车及其他玩家视角尚未全面双端验收。 |
| 箭、鱼钩和其他投射物 | 有独立的飞行／入地、水中、着火和并行动作输入；部分目标可查询发射者、投掷物品、鱼钩咬钩或命中对象。旧式箭资源也可导入。 | 爱丽丝原包的飞行箭和入地箭已有游戏绘制证据。该包里鱼钩和烟花提供静态外形，验收时要先确认作者是否为目标编写了动画。 |
| 弓弩发射物品 | 基岩版能保留发射时的弓或弩，让作者脚本切换箭上的不同骨骼。 | 爱丽丝发射与换木棍发生在同一游戏刻时，Java 实读取木棍，基岩版仍取弓／弩；延迟切手时 Java 可分别读到弓和弩。基岩版案例可用，同刻语义仍有已知差异。 |

若替换没有出现，先看实例 `mods/YsmBedrock/target-assignments-status.json` 中对应实体的 `feature_switch`、`ownership`、`target_match`、`animation`、`draw`。它们依次回答开关是否开启、归谁、命中哪个声明、选中什么动作、是否实际提交网格。到达 `draw` 后仍可能有材质或亮度差异。[目标匹配](../src/ModelTargets.cpp) · [归属](../src/ReplacedModelAssignments.cpp) · [原生绘制](../src/NativeReplacedResources.cpp) · [弓弩与三叉戟双端实机记录](https://github.com/XiaViolet/YsmBedrock/blob/ed61356b5df6f2ff275e555632c131f472fd3c26/docs/%E5%BC%93%E5%BC%A9%E4%B8%8E%E4%B8%89%E5%8F%89%E6%88%9F%E9%AA%8C%E6%94%B6.md)

| 0.29.2 的问题 | 开发源码中的改动 | 还需要什么证据 |
