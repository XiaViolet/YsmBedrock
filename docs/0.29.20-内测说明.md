# YsmBedrock 0.29.20 内测说明

Windows x64，Minecraft 1.26.60.05。编译依赖固定为 LeviLamina 客户端 26.60.7，安装脚本接受 26.60.7 或 26.60.8。

## 玩家操作

首次安装，在 LeviLauncher 的对应实例中导入 `YsmBedrock-0.29.20.mcmod`。升级时退出游戏，解压 `YsmBedrock-0.29.20-preview.zip`，在解压目录打开 PowerShell 并运行 `.\install.ps1 -Instance "实例目录"`。系统中已有的个人模型和设置由安装脚本保留。源码位于 `YsmBedrock-0.29.20-source.zip`。

新装模型库只有官方基础款 **Wine Fox（酒狐）**。模型来自 Java YSM 2.6.5 Fabric 1.21.1，43 个原始文件连同作者署名完整保留。模型采用 CC BY-NC-SA 4.0。自用模型可在模型库中导入。[官方发行](https://modrinth.com/mod/yes-steve-model/version/eGOUtHWJ) · [来源与校验](../licenses/wine-fox-source.json) · [许可](https://creativecommons.org/licenses/by-nc-sa/4.0/)

| 游戏内全局快捷键 | 用途 |
| --- | --- |
| Alt+Y | 打开模型库。换模、恢复原版、贴图及预览均可用鼠标操作。 |
| Z | 打开动作转盘。选动画后关窗播放，改装饰时可继续观察纸娃娃，动作锁在转盘中切换。 |

菜单内的数字选择、翻页、搜索输入、Esc 返回继续生效。原版游戏按键与作者脚本读取的键盘状态独立于模组全局快捷键。

## 修复与开销

- 快速换模时，只接受与当前选择修订号相符的房主批准，阻止延迟回包放行另一次选择。
- 单人世界跳过向不存在的对端准备姿态、肩上乘客和模型状态快照；使用原版外观且状态未改变时也省去重复广播。
- 房间缓存满额时可修复已被在线玩家占用的损坏模型，替换同一内容只预留所需额度，并为正在校验的任务保留空间。
- 远端玩家首次装入皮肤时，上传贴图与绑定资源均可访问正在安装的模型；提交给正式绘制后只调用一次。
- 空模型库中手工放入文件后，点刷新可重新发现模型，供预览或穿戴。
- 正常游戏略过面向调试的详细动画报告、菜单输入快照和周期状态文件。需要定位问题时，在 `mods/YsmBedrock` 下创建空文件 `diagnostics.enable` 并重启游戏，可查看动作调试叠层和详细报告。

## 验证范围

Windows Release 构建、键盘事件回放、动画与模型库回归、缓存与三节点房间协议回放覆盖了本批改动。首轮远端皮肤回调重放中，旧版首次绑定 0 次、交接上传 2 次，本版两者分别为 1 次。三节点回放覆盖提供者 → 房主 → 接收者、撤销权限、重连与缓存复用。局域网三名真实玩家、跨网好友房间、实际 GPU 画面和游戏帧率仍待实机验收。

本轮完整离线回归通过 958 项。独立安装目录的库扫描只选中 `ysm-wine-fox.zip`；回放与打包检查位于工程包的 `verification/`。
检查器从酒狐识别出 195 根主体骨骼、104 个动画片段、2 张可选贴图。原包声明的第三方联动动画组 `tac`、`carryon`、`tlm` 在基岩版尚未接入，保留原始声明。
