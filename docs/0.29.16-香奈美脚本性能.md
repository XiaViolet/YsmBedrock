# 香奈美的 parallel3

模型为未修改的香奈美生贺 v1.0.3。发布前后的源码目录指纹、计时、回放与游戏画面位于 `build/verification/perf-0.29.16`。测试基准为 Java Edition 1.21.1 的 YSM 2.6.5 正式 JAR，SHA-256 为 `a66b7265a2761d639c48f61a64179206adf5d81c38f360763fc8275a0fec9fa5`。固定源码用于追踪通用求值器，正式包里的老格式行为另行实测。

## 脚本热点

在完整播放器内仅对 parallel3 计数，预热后记录 72 个逻辑帧。该片段有 61 根受驱动的骨骼。最终同一时段串行 A/B 的片段时间线从 20.825 降至 11.528 ms/帧。下表为逐调用探针的自身时间，含实参求值并扣除嵌套调用。完整播放器另用未插桩的发行二进制按正反序复测，中位数分别从 24.11 / 24.06 降至 14.65 / 15.02 ms。逐帧数据与采样边界见 `profile-comparison.json` 和 `clip-profile-final-*.json`。

| 作者函数或查询 | 两版每帧次数 | 0.29.15 自身 ms | 0.29.16 自身 ms |
| --- | ---: | ---: | ---: |
| fn.quaternionandvector | 366 | 4.08 | 1.29 |
| fn.vectortovectorquaternion | 244 | 2.33 | 1.39 |
| fn.quaternionmultiply | 244 | 1.94 | 0.76 |
| fn.quaterniontool | 244 | 1.59 | 0.70 |
| math.sqrt | 878 | 1.36 | 0.59 |
| ysm.bone_pivot_abs | 726 | 0.67 | 0.62 |

每帧 `ysm.first_order` 仍求值 732 次。含子调用计时中，`fn.vectortovectorquaternion` 从 4.09 降到 2.25 ms。

共用解释器在编译时绑定算术操作和内置函数签名，数值表达式从变量、向量字段直接读取操作数。只对没有外部绑定依赖的子树复用访问校验结论。作者函数继续逐次执行，保留实参的从左到右求值、物理更新、预算和事件顺序。正式 DLL 不带分析器探针。

## 修正实际运动

0.29.15 可以显示尾巴，物理状态也会增加，但把写过 x/y/z 的临时变量传给作者函数时丢失了整个结构。静止与转身回放中的 61 根尾巴和发束骨骼局部旋转一直为零。0.29.16 在老格式环境中把这些字段作为可按值复制和返回的结构，常用坐标保存在值内。三角函数按正式版角度查表，逆三角函数返回弧度，老格式基本算术遵循 float 精度。asin/acos 的域外值保留其存在性，参与数值运算时投影为零，后面的时间线语句继续执行。

用正式 JAR 调香奈美的原作者函数，核对旋转向量、四元数乘法、平行、反向、直角和零向量。例子为将 (3,5,2) 绕 Y 轴转半圈，两端都得到 (−3,5,−2)。见 `record-java.log`、`original-quaternion-pairs.json` 与 `trig-java.log`。

原包另做两段各 76 帧的对照，均打开作者的尾巴选项 3。一段原地待机，另一段移动 0.58 格、转身 65° 再回到原位。尾根相对待机的局部轴角差平均为运动时 50.04°、停步后 45.01°，最后阶段回落至 0.14°。两段求值错误均为 0。详见 `kanami-motion-0.29.16.json`。原包另一个片段 `pre_parallel6 segment_6826_c` 的第 80 列仍有缺右括号诊断；Java 2.6.5 正式版解析同一原表达式也在这一列报错。

## 基岩版实机

测试实例为 1.26.60.05，世界为「YSM移植验证-20261113」。使用同一视角和地点，第三人称正面，满雨、空手、菜单关闭，作者尾巴保持默认。0.29.16 记录 36.27 秒、37 个 FPS 快照。旧版数据来自同一实例的 0.29.15 已存档测试。

| 游戏指标 | 0.29.15 | 0.29.16 |
| --- | ---: | ---: |
| 平均 FPS | 36.16 | 55.65 |
| 每次逻辑动画耗时 | 21.63 ms | 12.88 ms |

新版实机 FPS 范围为 52–58，游戏渲染回调为 56.24 次/秒。保持相同位置与视角，在作者尾巴选项 3 下另采 36.30 秒，37 个快照均值 55.86 FPS，范围 53–58，每次逻辑动画 12.93 ms。两个 FPS 均值相近，不能据此判断开启尾巴更快。该条件原始记录为 `game/0.29.16-tail3-rain-fps.json`。计时原始记录为 `game/0.29.16-tail0-rain-fps.json`，旧版在 `../perf-0.29.15/game/kanami-world-0.29.15-rain-stable.json`。

打开作者的选项 3 后，实机连续帧可见抬腿、下落、落地和发束与尾巴的延迟摆动，落地时记录了 218 个物理状态。新版一次下落中尾巴曾扫过身前。旧版与新版的采样时刻、游戏帧率不同，本轮没有同步比较 Java 客户端中整条尾巴的逐帧轨迹。见 `game/0.29.16-tail3-drop-sequence.jpg` 及 `game/0.29.16-tail3-walk-sequence.jpg`。

## 回归

自动测试 956 项通过。另用临战爱丽丝与 D 蓝色大肥鱼原包各回放 10 帧，覆盖待机、走路和使用弓。两版骨骼集合相同，新版无求值错误。最大骨骼通道数值差分别为 0.0010° 与 0.00019°，均出现在旋转通道。临战爱丽丝原有的 `parallel1 timeline 0` 诊断依然存在。三个模型包的内容指纹均与 0.29.15 记录一致。详见 `source-regression.json`、`tests-final.log`。
